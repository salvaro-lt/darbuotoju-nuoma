# Surface brief: app shell and back-office screens (apps/web/app)

Mode: Operate. Users: director, project manager, staff planner, on-site coordinator of a Lithuanian staffing company supplying welders/fitters to shipyards and steel projects abroad. Desktop, daily, dense lists (workers, certificates, teams, hours, invoices). LT default.

## Direction contract
THESIS: The system reads like a marked-up hull block in a shipyard: every screen sits on a frame-numbered rail. Refuses the default neutral SaaS shell (white cards, soft shadows, rounded pills, blue accent).
OWN-WORLD: Shop-primer grey ground, red-oxide accent for primary action and focus, paint-marker yellow only for warnings, near-black ink. Square-cornered plates with 1px hairlines, no soft shadows. Stencil display face only on page titles; condensed industrial grotesque (Barlow / Barlow Condensed) for UI; tabular figures everywhere numbers live.
STORY: People see where they are (frame ruler + stencil title), what needs attention (yellow/oxide marks), and act fast in dense tables.
SIGNATURE: The frame ruler: tick marks with FR numbers along the sidebar edge and under page headers, like draught marks on a hull.
STATE GRAMMAR (raise from emission-line challenger): state carried by form as well as hue: solid mark = valid, dashed = expiring, struck-through = expired, hollow = missing.
RISK: Industrial theming can tip into costume; keep stencil to titles only, keep body calm and legible.
